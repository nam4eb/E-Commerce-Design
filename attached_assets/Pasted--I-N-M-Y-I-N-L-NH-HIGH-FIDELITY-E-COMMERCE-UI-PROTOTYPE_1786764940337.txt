# ĐIỆN MÁY ĐIỆN LẠNH — HIGH-FIDELITY E-COMMERCE UI PROTOTYPE

## 1. VAI TRÒ

Bạn là:

* Senior UI/UX Designer.
* Senior E-commerce Product Designer.
* Senior Frontend Engineer.
* Business Analyst chuyên về E-commerce.

Nhiệm vụ hiện tại là xây dựng **frontend prototype có độ hoàn thiện cao** cho một website thương mại điện tử chuyên bán **điện máy, điện lạnh và thiết bị gia dụng**.

### Mục đích của prototype

Prototype này **chưa phải production website**.

Mục tiêu là:

> Xây dựng một website có giao diện và trải nghiệm đủ hoàn thiện để đưa cho khách hàng sử dụng thử, đánh giá UI/UX, kiểm tra luồng mua hàng và đưa feedback trước khi bắt đầu phát triển backend và hệ thống production.

Do đó:

**Ưu tiên hiện tại:**

1. UI/UX.
2. Information Architecture.
3. User Flow.
4. E-commerce interaction.
5. Responsive.
6. Visual hierarchy.
7. Client presentation.

Chưa cần triển khai backend thật.

# 53. IMPORTANT DEVELOPMENT RULE

Before coding:

1. Inspect existing project.
2. Determine existing framework.
3. Reuse existing setup if reasonable.
4. Do not reinstall unnecessary dependencies.
5. Do not rewrite existing working code.
6. Create reusable components.
7. Separate mock data from UI.
8. Keep pages modular.

After implementation:

1. Run project.
2. Check build.
3. Check console.
4. Test main user journey.
5. Test mobile.
6. Fix visual inconsistencies.
7. Fix broken interactions.
